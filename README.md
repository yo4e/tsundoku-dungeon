# 積読ダンジョン

> **人は老いる。だが読む。**

本棚の奥へ潜り、限られた読書人生の中で「何を読むか」を選ぶ、PC・スマホ対応の短時間ローグライクです。背表紙のあいだを歩き、読む、抱える、見送る。未読本を抱えすぎれば積読は重くなり、余白は減り、歳を重ねるほど近くの活字はほどけていきます。それでも、読んだ本はあなたの道具になります。

**公開版:** [yo4e.github.io/tsundoku-dungeon](https://yo4e.github.io/tsundoku-dungeon/)

## このリポジトリに含まれるもの

| 区分 | 内容 |
|---|---|

| 企画資料 | コンセプト、ゲームループ、ジャンル別能力、補助具、プレイ時間設計を `docs/` に記録しています。 |

| 実装資料 | 状態遷移、モジュール分割、描画・入力方針、検証方法を記録しています。 |
| 制作メモ | `PLAN.md`、`STRUCTURE.md`、`ASSETS.md`、`MEMORY.md`、`ideas.md` に制作時の判断と資産情報を残しています。 |

## 遊び方

探索は、矢印キーまたは **WASD**、スマホでは盤面のスワイプまたは方向ボタンで行います。背表紙のセルに入ると、その本を「今、読む」「抱える」「棚に残す」から選べます。読むと一手と時間を使う代わりに能力を獲得し、抱えると後で返却台にて読めますが、余白は狭くなります。

最奥の梯子を目指して4章を渡ります。余白が尽きると今夜の探索は終わり、クリア・ゲームオーバーのどちらでも、最後に同じ言葉が残ります。

## 開発環境

```bash
pnpm install
pnpm dev
```

開発サーバー起動後、`/` で表紙画面を、`/?demo` で固定ルートの自動探索デモを確認できます。

```bash
pnpm check
pnpm build
```
