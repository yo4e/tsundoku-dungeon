# ゲームデザイン — 読む、抱える、見送る

## 基本ループ

探索中、プレイヤーは一手ずつ書架迷路を進む。本のセルに入ると読書選択に移る。本を読むと時間が進み、能力を記憶できる。本を抱えると積読として後で返却台で読み直せるが、余白の上限が下がる。本を見送れば時間を使わず、別の選択肢を探せる。

| 選択 | 即時の変化 | 中長期の意味 |
|---|---|---|
| 今、読む | 余白を1使い、年輪を進める。 | 能力を得て盤面の読み方を変える。記憶枠は3冊まで。 |
| 抱える | その場では読まない。 | 積読が増え、余白の上限が下がる。返却台で安全に読める。 |
| 棚に残す | 状態は変わらない。 | 余白と記憶枠を温存し、もっと必要な本へ進める。 |

## ステータス

| 指標 | 意味 | 初期・運用 |
|---|---|---|
| 年齢 | 時間経過を示す年輪。 | 38歳から始まり、5手ごとに1歳進む。章を越えるとさらに2歳進む。 |
| 余白 | 行動力。0になると今夜の探索が終わる。 | 章開始時は22。返却台や料理本で戻せる。 |
| 文字の輪郭 | 近くの本の本文を読める程度。 | 年齢と積読で下がり、補助具で戻る。操作UIの可読性は常に確保する。 |
| 積読 | 抱えた未読本。最大4冊。 | 2冊目以降は余白上限を下げる。返却台で読めば解消する。 |
| 記憶の棚 | 読了した本の能力。最大3冊。 | 4冊目を読んだときは、過去の能力を手放すか今回だけの読書にする。 |

## ジャンル別の能力

| ジャンル | 能力 | 効果 | 選択上の位置づけ |
|---|---|---|---|
| SF | 予見 | 次の棚にある本の見通しを欄外に残す。 | 早めに読むほど、次章以降の選書を助ける。 |
| ミステリ | 推理 | 各章1回、出口へ通じる手掛かりを示す。 | 余白を節約できるが、記憶枠を使う。 |
| 文学 | 余韻 | 返却台での回復を増やし、年齢を少し和らげる。 | 寄り道と休息を価値ある選択にする。 |
| 哲学 | 逡巡 | 各章1回、直前の一歩へ戻る。 | 読み違い・遠回りに対する保険になる。 |
| 実用書 | 段取り | 積読1冊ぶんの負荷を軽くする。 | 抱えて後で決める戦略を可能にする。 |
| 料理本 | 滋養 | 読了時に余白を戻し、休息の回復を増やす。 | 進行を支える短期的な回復札になる。 |

## 読書補助具

| 補助具 | 効果 | 戦略上の意味 |
|---|---|---|
| 老眼鏡 | 文字の輪郭を大きく戻す。 | 高年齢・高積読の読書を可能にする。 |
| 遠近両用コンタクト | 輪郭を戻し、棚の奥行きを扱いやすくする。 | 序盤から安定した読書環境を作る。 |
| 電子書籍端末 | 輪郭の最低値を保ち、積読を1冊ぶん軽くする。 | 「抱えて後で読む」戦略をより現実的にする。 |
| 読書灯 | 輪郭を戻し、返却台での回復を増やす。 | 休息中心のルートを支える。 |

## 返却台

各章には返却台を置く。返却台では、余白を回復するか、抱えた積読を一冊開いて読むかを選べる。積読を拾う行為が単なる罰にならないよう、返却台は「後で読む」という先送りを戦略として成立させる場所である。

## 難易度の考え方

難しさは敵の強さではなく、**時間と選択肢の密度**で増す。各章で本・補助具・出口を同時に見ることはできても、すべてに立ち寄れるとは限らない。必要な能力、今の余白、積読の重さ、読みやすさを比較して、今夜の一冊を決める。
