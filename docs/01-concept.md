# コンセプト — 読めなかった本の地層へ

## 一行でいうと

**「積読ダンジョン」は、積み上がった本を抱えながら、自分の読み方を選び直す人のための短時間ローグライクである。**

プレイヤーが歩く場所は、現実の本棚の奥に生まれた小さな迷宮である。壁は積み重なった本、拾得物は読むための道具、出口は次の棚へ降りる梯子だ。敵を倒す代わりに、どの本に自分の時間を渡すかを選ぶ。読書は強化であると同時に、年輪を進める行為でもある。

## 体験の核

| 柱 | 体験として実現したいこと | ゲーム上の表現 |
|---|---|---|
| 選書 | 「全部読む」より、今の自分に必要な本を選ぶ。 | 本は能力をくれるが、読むたびに余白と時間を使う。 |
| 積読 | 未読本は可能性であり、物理的な重みでもある。 | 抱えた本は後で返却台で読めるが、行動力上限を圧迫する。 |
| 老い | 変化は罰ではなく、読書環境を工夫する理由になる。 | 年齢に応じて可読性が下がり、補助具が戦略になる。 |
| 余韻 | 成功しても、読まなかった本が残る。 | クリア時・敗北時ともに同じ終章の言葉を表示する。 |

## プレイ時間と構造

1ランは全4章の書架で構成する。各章は9×7セルの小さな探索盤で、書架壁、本、補助具、返却台、出口梯子を含む。数十手の中で何冊かの本に出会い、最奥まで進めば次の棚へ移る。1プレイは10〜20分を目標とし、セーブデータを持たない。

各章を通じて、プレイヤーは「余白」「文字の輪郭」「積読」「記憶の棚」を管理する。余白は行動力であり、尽きれば探索は終わる。文字の輪郭は本の本文の読みにくさにだけ影響し、操作UIそのものを不当に読みにくくはしない。

## 何をしないか

このゲームは蔵書数の最大化を目的にしない。全ジャンルを揃えること、全ての本を抱えること、最短経路だけを走ることが、常に最適にならないようにする。戦闘、反射神経、複雑なアイテムクラフトも主題にしない。選択の代償を読み、必要な一冊を記憶に置くことを主題にする。

## 終章の言葉

クリア・ゲームオーバーともに、次の文を表示する。

> **人は老いる。だが読む。**
