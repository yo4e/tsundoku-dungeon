# アートディレクション — 書庫銅版画

## デザイン運動

ビジュアルの基調は、**19世紀の博物画・銅版画**と、和製古書の装丁・見返し・欄外注である。本棚を単なる背景にせず、迷路そのものを「読めなかった本の地層」として見せる。派手なファンタジーより、深夜の机上から一歩だけ踏み外した先にありそうな異界を目指す。

## 見開き頁の構成

ゲームは中央カードを積み重ねるUIではなく、**左に書架迷路、右に欄外注**を置く見開き頁として設計する。左側には背表紙の壁、未読本、梯子、返却台を置き、右側には年齢、余白、文字の輪郭、積読、記憶の棚、補助具を紙の欄外のように積む。スマホでは欄外を盤面下部の栞型情報帯へ畳む。

| 要素 | デザイン上の役割 | 実装上の扱い |
|---|---|---|
| 蔵書票印章 | 「本棚の奥へ降りる」ブランドの入口。 | 三冊の背表紙が階段にも見える記号を、表紙・ヘッダー・ファビコンに置く。 |
| 欄外注 | 状態情報を世界観内に置く。 | 明朝の小見出し、等幅の数値、細い罫線で構成する。 |
| 朱墨 | 開始、読む、代償、稀少な発見を示す。 | 署名色 `#C84A36` に限定して使う。 |
| 黄銅 | 出口、進行、獲得感を示す。 | 梯子、導線、ささやかな罫線に用いる。 |
| 生成り | 読むための紙面と文字。 | 暗い書架背景でも本文を読ませる。 |

## 色彩

| 名称 | 色 | 意図 |
|---|---:|---|
| 墨紺 | `#0B0D22` | 深夜の書庫。暗くても黒潰れさせない背景。 |
| 生成り | `#F7EAD0` | 紙、本文、主見出し。温かい高コントラスト。 |
| 朱墨 | `#C84A36` | 開始・読書・不可逆な選択の署名色。 |
| 黄銅 | `#D9B66B` | 梯子、ガイド、静かな到達感。 |
| 胡桃 | `#785542` | 返却台、古書の木部、休息の温度。 |

## タイポグラフィ

見出しは `Noto Serif JP` を使い、古書の余白を感じる広めの字間を取る。本文は `Noto Sans JP` を使い、読みやすさを優先する。年齢、余白、セル座標、操作のような情報は `IBM Plex Mono` を使い、ゲームの状態を「注釈」として読み分けられるようにする。

年齢による可読性低下は、ゲーム内の本情報にだけ適用する。プレイヤーが本当に操作できなくなることを避けるため、方向ボタン、余白ゲージ、主要選択肢は常に十分なコントラストとサイズを保つ。

## 動き

移動は短いスライドと影の変化だけで表現する。読書の瞬間だけ紙片がひらくような小さな変化を置き、朱墨と黄銅の色が一度走る。積読が重いほど盤面側の余韻はわずかに長くするが、入力への反応は遅らせない。動きの軽減を希望する環境では、全て静的なフェードに置き換える。

## 生成アセット

生成したアセットのURL、役割、表示サイズは [`ASSETS.md`](../ASSETS.md) に記録している。大きな背景、ロゴ、読者と補助具の図版、ジャンル別の本セットを使い、情報ゲージ・罫線・方向ボタンのような小さな幾何要素はコードで描画する。
